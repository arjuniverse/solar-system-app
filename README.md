☀️ SolarVerse

Interactive AI-Powered Solar System Simulator

SolarVerse is an interactive web application that allows users to explore and visualize the solar system through dynamic simulations. Users can interact with planets, customize orbital parameters, and generate realistic solar system animations for learning and exploration.

⸻

✨ Features

🌍 Interactive Solar System
	•	Explore all eight planets and the Sun in a 3D environment.
	•	Zoom, rotate, and navigate freely around celestial bodies.
	•	Click on planets to view detailed information.

🚀 Dynamic Simulation
	•	Real-time planetary motion based on orbital mechanics.
	•	Adjustable simulation speed.
	•	Pause, resume, and reset simulations.

🎨 Custom Solar System Generator
	•	Create custom planetary systems.
	•	Modify planet size, orbit radius, speed, and colors.
	•	Add or remove celestial bodies dynamically.

🤖 AI Simulation Generator
	•	Generate unique solar system layouts from user prompts.
	•	Automatically configure planetary arrangements and orbital properties.
	•	Visualize AI-generated planetary systems instantly.

📊 Planet Information
	•	Distance from the Sun
	•	Diameter
	•	Orbital Period
	•	Rotation Period
	•	Surface Temperature
	•	Planet Type

🎥 Smooth Animations
	•	Realistic orbital movements.
	•	Camera transitions and zoom effects.
	•	Responsive interactions for desktop and mobile.
