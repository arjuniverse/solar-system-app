# ☀️ SolarVerse



### 🤖 AI Solar System Generator
- Generate unique solar system simulations from user prompts.
- Create custom planets with adjustable size, orbit, speed, and color.
- Instantly visualize AI-generated planetary systems.

### 📊 Planet Information
- Planet type
- Diameter
- Distance from the Sun
- Orbital period
- Rotation period
- Surface temperature

### 🎨 Interactive Experience
- Real-time user interaction with planets.
- Responsive design for desktop and mobile.
- Smooth camera controls and transitions.
